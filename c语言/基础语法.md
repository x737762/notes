## 数据类型

c 语言中数据类型有 3 种，分别是基本数据类型、构造数据类型、指针数据类型。

## 布尔类型

- 早期 c 语言没有布尔类型数据，以 0 代表逻辑假，非 0 代表逻辑真；
- C99 标准定了新的关键字`_Bool`，提供了布尔类型，或者也可以使用`stdbool.h`中的`bool`。

```c
#include <stdbool.h>
#include <stdio.h>

int main() {
  // 布尔类型
  bool flag = true;
  printf("flag: %d", flag);

  return 0;
}

```

## 可移植类型

c 语言在可移植类型头文件 `stdint.h`和`inttype.h`中规定了精确宽度整数类型，以确保 c 语言的类型在各操作系统内功能相同。

```c
#include <stdint.h>
#include <stdio.h>

int main() {

  // 8位整型
  int8_t i = 127;
  printf("int8: %d\n", i);

  int8_t a = 128;
  printf("int8: %d\n", a); // -128

  // unsigned 无符号，数值为正数
  uint8_t u = 255;
  printf("uint8: %d\n", u);

  uint8_t b = 256;
  printf("uint8: %d\n", b); // 0，只保留后8位

  return 0;
}
```

## 基本数据类型长度

数据类型长度会受操作系统平台的影响，所以在不同平台下基本数据类型的长度是不一样的。

| 数据类型    | 长度（字节） |
| ----------- | ------------ |
| char        | 1            |
| short       | 2            |
| int         | 4            |
| long        | 4 或 8       |
| float       | 4            |
| double      | 8            |
| long double | 16 或更多    |
| void        | 无大小       |

使用`sizeof`获取各种类型的长度(字节)。

```c
#include <stdio.h>

int main() {

  printf("shar size: %d\n", sizeof(char));
  printf("short size: %d\n", sizeof(short));
  printf("int size: %d\n", sizeof(int));
  printf("long size: %d\n", sizeof(long));
  printf("float size: %d\n", sizeof(float));
  printf("double size: %d\n", sizeof(double));
  printf("long double size: %d\n", sizeof(long double));

  int a = 100;
  printf('a size: %d\n', sizeof(a));

  return 0;
}
```

## 常量

- 预处理常量：`#define PI 3.1415926535`
- const 常量：`const int e = 2.79;`

c 语言提供了一些常量库，比如：`float.h`、`limits.h`等，这些常量同样受操作系统平台的影响，会在不同的平台下不一样。

```c
#include <stdio.h>

#define PI 3.1415926535 // 预处理常量

int main() {
  const double e = 2.7182; // const 常量

  printf("PI: %.10f\n", PI);
  printf("e: %f\n", e); // %f默认打印小数点后六位
  return 0;
}
```
